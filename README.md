# سامانه مدیریت دبیرستان سید احمد خمینی

پروژه سامانه مدرسه برای مدیریت امن دانش‌آموزان، والدین، دبیران، کلاس‌ها و اطلاعات آموزشی. زبان رابط محصول فارسی و جهت آن راست‌به‌چپ خواهد بود.

## وضعیت فعلی

صفحهٔ مدرسه و پایهٔ ورود امن محلی اکنون پیاده‌سازی شده‌اند. پنل‌های عملیاتی مدرسه و APIهای آموزشی هنوز کامل نیستند؛ این پروژه را آمادهٔ استفادهٔ مدرسه یا تولید فرض نکنید. محیط در [IMPLEMENTATION-STATUS.md](IMPLEMENTATION-STATUS.md) و برنامهٔ مرحله‌ای در [BUILD-PLAN.md](BUILD-PLAN.md) ثبت شده است.

## پیش‌نیازهای موردنظر

- Node.js نسخهٔ ۲۲٫۱۳ یا جدیدتر و npm.
- SQLite داخلی Node.js برای اجرای محلی فعلی؛ PostgreSQL برای استقرار آینده.
- Docker Compose برای راه‌اندازی بازتولیدپذیر سرویس‌های محلی، در صورت فراهم شدن Docker.
- دسترسی registry بسته‌های npm برای نصب وابستگی‌ها.

برای نصب وابستگی‌ها در ویندوز `npm.cmd install` و برای اجرا `npm.cmd run dev` را در پوشه پروژه اجرا کنید. جزئیات در `LOCAL-SETUP.md` آمده است.

## اصول دامنه و حریم خصوصی

- هر دانش‌آموز و والد حساب مستقل دارد و ارتباط میان آن‌ها چندبه‌چند است.
- غیبت تنها به سرپرست ثبت‌شده و تأییدشده اعلان می‌شود؛ شماره دانش‌آموز هرگز مسیر جایگزین خودکار نیست.
- در توسعه، پیامک باید با ارائه‌دهنده ساختگی ثبت شود. ارسال واقعی مستلزم پیکربندی مجاز سمت سرور است.
- بررسی مجوز در API الزامی است؛ محدودکردن رابط کاربری به‌تنهایی مجوز دسترسی محسوب نمی‌شود.
- قابلیت کلاس زنده تا زمان پیکربندی واقعی سرویس رسانه در دسترس اعلام نخواهد شد.
